# សៀវភៅណែនាំអតិថិជន

**School Management System · V1 + V2 (0.14.0)**  
ប្រព័ន្ធគ្រប់គ្រងសាលាភាសាអង់គ្លេស និងកុំព្យូទ័រ · សាខាតែមួយ · Admin Portal

ឯកសារនេះសម្រាប់ម្ចាស់សាលា និងអ្នកគ្រប់គ្រង ដើម្បីយល់ថាប្រព័ន្ធធ្វើអ្វីបានខ្លះ និងរបៀបប្រើក្នុងការងារប្រចាំថ្ងៃ។

---

## 1. ប្រព័ន្ធនេះជាអ្វី?

វាជាគេហទំព័រគ្រប់គ្រងសាលា សម្រាប់ **អ្នកគ្រប់គ្រង (Admin)** ប្រើនៅការិយាល័យ។

បន្ទាប់ពីចូលប្រព័ន្ធ អ្នកអាច៖

- រក្សាព័ត៌មានសិស្ស និងថ្នាក់រៀន
- ទទួលបង់ថ្លៃសិក្សា រួចចេញបង្កាន់ដៃភាសាខ្មែរ លើក្រដាស A4
- មើលនរណាមិនទាន់បង់ ឬហួសថ្ងៃកំណត់ (Due Date)
- មើលចំណូលជា USD និង KHR ដាច់ពីគ្នា
- ទាញរបាយការណ៍ Excel ឬបោះពុម្ព
- ទទួលការរំលឹកតាម Telegram (ទៅ Admin តែប៉ុណ្ណោះ)

V1 មាន **សាខាតែមួយ**។ V2 បន្ថែមតួនាទី **Admin · អ្នកគិតលុយ · គ្រូបង្រៀន** ក្នុងផតថលតែមួយ។ ឪពុកម្តាយ និងសិស្សមិនមានគណនីចូលផ្ទាល់ទេ។

---

## 2. របៀបចូលប្រព័ន្ធ

1. បើកគេហទំព័រដែលសាលាបានទទួល (ឧទាហរណ៍ `https://សាលា.com`)
2. បញ្ចូល **ឈ្មោះអ្នកប្រើ** និង **ពាក្យសម្ងាត់**
3. ចុច **ចូលប្រព័ន្ធ**

ប្រសិនបើភ្លេចពាក្យសម្ងាត់ ឬចូលខុសច្រើនដង សូមទាក់ទងអ្នកគ្រប់គ្រងប្រព័ន្ធ។ ចូលខុសច្រើនដងនឹងត្រូវចាក់សោបណ្ដោះអាសន្ន។

បន្ទាប់ពីចូលរួច ម៉ឺនុយនៅខាងឆ្វេងមាន៖

| ម៉ឺនុយ | ប្រើសម្រាប់ |
| --- | --- |
| ផ្ទាំងគ្រប់គ្រង | មើលស្ថានភាពប្រចាំថ្ងៃ |
| សិស្ស | បញ្ជីសិស្ស និងព័ត៌មាន |
| វគ្គសិក្សា | កំណត់វគ្គ និងថ្លៃ |
| ថ្នាក់រៀន | កាលវិភាគ និងសិស្សក្នុងថ្នាក់ |
| ការបង់ប្រាក់ | ទទួលបង់ · លុបចោល · សង |
| បង្កាន់ដៃ | មើល និងបោះពុម្ព |
| របាយការណ៍ | ចំណូល និងស្ថានភាពបង់ |
| អ្នកប្រើប្រាស់ | បន្ថែម/ផ្អាក Admin |
| Audit Log | ប្រវត្តិសកម្មភាព |
| ការកំណត់ | ឈ្មោះសាលា · Telegram · Backup |

កណ្ដឹងនៅខាងលើនាំទៅបញ្ជី Due Date លើផ្ទាំងគ្រប់គ្រង។

## 3. លំហូរការងារណែនាំ (ចាប់ផ្ដើមប្រើ)

ធ្វើតាមលំដាប់នេះម្តង ពេលដំឡើងថ្មី៖

1. **ការកំណត់** — បំពេញឈ្មោះសាលា អាសយដ្ឋាន ទូរសព្ទ និមិត្តសញ្ញា
2. **វគ្គសិក្សា** — បង្កើតវគ្គ (ឧ. English Kids, Computer Basic) រួចកំណត់ថ្លៃ និងរូបិយប័ណ្ណ
3. **ថ្នាក់រៀន** — បង្កើតថ្នាក់ក្នុងវគ្គ រួចដាក់ថ្ងៃសិក្សា ម៉ោង គ្រូ
4. **សិស្ស** — បញ្ចូលសិស្សថ្មី
5. **ដាក់សិស្សចូលថ្នាក់** — មិនមានម៉ឺនុយ «ចុះឈ្មោះ» នៅខាងឆ្វេង។ ធ្វើនៅក្នុងទំព័រសិស្ស ឬទំព័រថ្នាក់ (មើលខាងក្រោម)
6. **ទទួលបង់** — ពេលសិស្សបង់ថ្លៃ ប្រព័ន្ធចេញបង្កាន់ដៃភ្លាម

**របៀបដាក់សិស្សចូលថ្នាក់ (ចំណុចទី ៥)** — ជ្រើសមួយក្នុងពីរវិធីនេះ៖

- **ពីសិស្ស៖** ម៉ឺនុយ **សិស្ស** → ចុចឈ្មោះសិស្ស → ប្រអប់ខាងស្តាំ **ចុះឈ្មោះថ្នាក់ថ្មី** → ជ្រើសថ្នាក់ → កំណត់ Due Date → ចុច **ចុះឈ្មោះ**
- **ពីថ្នាក់៖** ម៉ឺនុយ **ថ្នាក់រៀន** → ចុចឈ្មោះថ្នាក់ → **+ ចុះឈ្មោះសិស្ស** → ជ្រើសសិស្ស → កំណត់ Due Date → ចុច **ចុះឈ្មោះ**

ការងារប្រចាំថ្ងៃបន្ទាប់មកជាធម្មតា៖ បញ្ចូលសិស្សថ្មី → ដាក់ចូលថ្នាក់ → ទទួលបង់ → បោះពុម្ពបង្កាន់ដៃ → មើលនរណាហួស Due Date។

---

## 4. ផ្ទាំងគ្រប់គ្រង

ទំព័រដំបូងបង្ហាញ៖

- ចំនួនសិស្សសរុប និងសិស្សកំពុងរៀន
- ប្រាក់ចំណូល **ថ្ងៃនេះ** និង **ខែនេះ** (USD និង KHR ដាច់ពីគ្នា)
- ចំនួនសិស្សមិនទាន់បង់ និងហួស Due Date
- បញ្ជីសិស្សជិតដល់ Due Date / ហួស Due Date
- ការបង់ថ្មីៗ

ពីទីនេះអាចចុចទៅ **ចុះឈ្មោះសិស្ស** ឬ **ទទួលបង់ប្រាក់** ភ្លាម។

## 5. សិស្ស

### បន្ថែមសិស្ស

ចុច **+ បន្ថែមសិស្ស**។ ប្រព័ន្ធផ្តល់លេខសម្គាល់ស្វ័យប្រវត្តិ៖

`STU-ឆ្នាំ-0001`  
ឧទាហរណ៍៖ `STU-2026-0001`

ព័ត៌មានដែលអាចរក្សាទុក៖

- រូបថត · ឈ្មោះខ្មែរ · ឈ្មោះអង់គ្លេស · ភេទ
- ថ្ងៃកំណើត · ទូរសព្ទ · អ៊ីមែល · អាសយដ្ឋាន
- អាណាព្យាបាល និងលេខទូរសព្ទ
- កំណត់ចំណាំ

### ទំព័រសិស្ស និងដាក់ចូលថ្នាក់

ចុចឈ្មោះសិស្សក្នុងបញ្ជី (កុំរកម៉ឺនុយ «ចុះឈ្មោះ» នៅខាងឆ្វេង)។ នៅទំព័រសិស្សមាន៖

- ព័ត៌មានទំនាក់ទំនង
- ប្រអប់ **ចុះឈ្មោះថ្នាក់ថ្មី** នៅខាងស្តាំ — ជ្រើសថ្នាក់ រួចកំណត់ Due Date ដោយដៃ
- ប្រវត្តិចុះឈ្មោះ (ខាងក្រោម)
- ប្រវត្តិវត្តមាន · ប្រវត្តិពិន្ទុ
- ប្រវត្តិបង់ប្រាក់

វិធីទីពីរ៖ ចូល **ថ្នាក់រៀន** → ចុចឈ្មោះថ្នាក់ → ចុច **+ ចុះឈ្មោះសិស្ស** (popup)។

### ផ្ទេរ / ប្ដូរស្ថានភាព

ស្ថានភាពការចុះឈ្មោះ៖ **កំពុងរៀន · ផ្អាក · បោះបង់ · ផ្ទេរ · បញ្ចប់**

- **ផ្ទេរថ្នាក់** — កំណត់ត្រាចាស់ប្ដូរទៅ «ផ្ទេរ» ហើយបង្កើតការចុះឈ្មោះថ្មី។ ប្រវត្តិចាស់មិនបាត់។
- មិនអាចលុបប្រវត្តិចុះឈ្មោះបានទេ។

## 6. វគ្គសិក្សា និងថ្នាក់រៀន

### វគ្គសិក្សា

កំណត់៖

- ឈ្មោះវគ្គ
- ប្រភេទថ្លៃ៖ **ប្រចាំខែ** · **គិតតាមវគ្គ** · **មួយលើក**
- ថ្លៃសិក្សាលំនាំដើម
- រូបិយប័ណ្ណ **USD** ឬ **KHR** (ជ្រើសមួយ មិនបម្លែងគ្នាទេ)

### ថ្នាក់រៀន

ក្នុងវគ្គមួយអាចមានច្រើនថ្នាក់។ ថ្នាក់មាន៖

- ឈ្មោះថ្នាក់ · ឈ្មោះគ្រូ
- ថ្ងៃចាប់ផ្ដើម / បញ្ចប់
- ថ្ងៃសិក្សា (ច័ន្ទ–អាទិត្យ) និងម៉ោង
- បញ្ជីសិស្សក្នុងថ្នាក់

ពីទំព័រថ្នាក់ ចុច **+ ចុះឈ្មោះសិស្ស** ដើម្បីដាក់សិស្សចូលថ្នាក់នេះ (ជ្រើសសិស្ស + Due Date)។ ក្នុងបញ្ជីសិស្សអាចចុច **បង់** សម្រាប់សិស្សកំពុងរៀន។

ទំព័រថ្នាក់ជា**ផ្ទាំងថ្នាក់**៖ ចុច **វត្តមាន** · **ពិន្ទុ** · **លទ្ធផល** ដើម្បីចូលទៅកន្លែងបញ្ចូល ឬមើល។ មិនមានម៉ឺនុយវត្តមាន/ពិន្ទុដាច់ដោយឡែក។

### វត្តមាន

ចូល **ថ្នាក់រៀន** → ចុចថ្នាក់ → **វត្តមាន**។ តារាង៖ ល.រ · ID · ឈ្មោះ · ភេទ · ថ្ងៃទី (dropdown បើមួយថ្ងៃ) · សរុប (វត្តមាន · យឺត · សុំច្បាប់ · អវត្តមាន)។ ពីថ្ងៃ–ដល់ថ្ងៃ៖ ដាក់ថ្ងៃដូចគ្នាដើម្បីចុះ; រើសចន្លោះដើម្បីមើលសរុប។

- ស្ថានភាព៖ **វត្តមាន** · **យឺត** · **សុំច្បាប់** · **អវត្តមាន**
- ជ្រើសក្នុង dropdown ក្រោមថ្ងៃទី រួចរក្សាទុក — កំណត់ត្រាចាស់មិនលុប
- ថ្ងៃមិនមែនថ្ងៃសិក្សានៅតែចុះបាន (ឧ. ថ្នាក់បំពេញ)
- **គ្រូ** ចុះបានតែថ្នាក់ខ្លួន។ **Admin** ចុះគ្រប់ថ្នាក់។ **អ្នកគិតលុយ** មិនមើល ឬចុះវត្តមាន
- Admin មើលរបាយការណ៍វត្តមានក្នុង **របាយការណ៍**
- ទំព័រសិស្សបង្ហាញប្រវត្តិវត្តមាន (គ្រូឃើញតែថ្នាក់ខ្លួន)

### ពិន្ទុ

ចូល **ថ្នាក់រៀន** → ចុចថ្នាក់ → **ពិន្ទុ**។ ប្លង់ដូចវត្តមាន៖ តារាងសិស្ស (ល.រ · ID · ឈ្មោះ · ភេទ)។

1. ចុច **+ បង្កើតប្រឡង** (popup) — ឈ្មោះ · ថ្ងៃ · ពិន្ទុពេញ
2. ជ្រើសប្រឡងក្នុង dropdown រួច **បើក**
3. បញ្ចូលពិន្ទុក្នុងជួរប្រឡង រួច **រក្សាទុកពិន្ទុ**
4. សរុប · មធ្យម · និទ្ទេសបង្ហាញនៅចុងតារាង — កំណត់ត្រាចាស់មិនលុប

**គ្រូ** ដាក់បានតែថ្នាក់ខ្លួន។ **Admin** គ្រប់ថ្នាក់។ **អ្នកគិតលុយ** មិនមើល។ ទំព័រសិស្សបង្ហាញប្រវត្តិពិន្ទុ (គ្រូឃើញតែថ្នាក់ខ្លួន)។

### លទ្ធផល

ចូល **ថ្នាក់រៀន** → ចុចថ្នាក់ → **លទ្ធផល**។ មុខវិជ្ជា = វគ្គនៃថ្នាក់នោះ។ តារាងបង្ហាញពិន្ទុតាមប្រឡង · សរុប · មធ្យម (%) · និទ្ទេស។

និទ្ទេស៖ **A** ៩០–១០០ ល្អប្រសើរ · **B** ៨០–៨៩ ល្អណាស់ · **C** ៧០–៧៩ ល្អ · **D** ៦០–៦៩ មធ្យម · **E** ៥០–៥៩ ខ្សោយ · **F** ក្រោម ៥០ ធ្លាក់។

មិនមានប័ណ្ណពិន្ទុ។

## 7. ការបង់ប្រាក់ និងបង្កាន់ដៃ

### ទទួលបង់

ចូល **ការបង់ប្រាក់** → ទម្រង់ទទួលបង់។

1. ជ្រើស **សិស្ស / ថ្នាក់**
2. បញ្ចូលថ្ងៃបង់ និងធាតុថ្លៃ
3. ជ្រើសវិធីបង់
4. **Due Date បន្ទាប់** សម្រាប់វគ្គប្រចាំខែ៖ បង់ពេញរួច ប្រព័ន្ធដាក់ស្វ័យ (+១ ខែ)។ បង់ផ្នែកខ្លះ នៅ Due Date ដដែល។ អាចកែមុនរក្សាទុក។
5. រក្សាទុក — ប្រព័ន្ធចេញបង្កាន់ដៃភ្លាម

ធាតុថ្លៃដែលអាចមាន៖

- ថ្លៃសិក្សា
- ថ្លៃចុះឈ្មោះ
- ថ្លៃយឺត (**បញ្ចូលដោយដៃ** មិនគិតស្វ័យប្រវត្តិ)
- បញ្ចុះតម្លៃ
- អាហារូបករ

**សរុបត្រូវបង់** = ថ្លៃសិក្សា + ថ្លៃចុះឈ្មោះ + ថ្លៃយឺត − បញ្ចុះតម្លៃ − អាហារូបករ

វិធីបង់ដែលមានស្រាប់៖ **Cash · ABA · ACLEDA · Wing · KHQR**  
ABA / ACLEDA / Wing / KHQR ត្រូវការ **លេខយោងប្រតិបត្តិការ**។ Cash មិនត្រូវការ។

**តើប្រព័ន្ធបង្កើតថ្លៃខែថ្មីដោយខ្លួនឯងទេ?**  
ទេ។ មិនបង្កើតវិក្កយបត្រខែស្វ័យប្រវត្តិ។ បន្ទាប់ពីបង់**ពេញ**វគ្គប្រចាំខែ ប្រព័ន្ធដាក់ Due Date បន្ទាប់ (+១ ខែ)។ បង់ផ្នែកខ្លះ Due Date នៅដដែល។

**ហេតុអ្វី USD និង KHR មិនបូកចូលគ្នា?**  
ដើម្បីឲ្យចំនួនត្រឹមត្រូវ មិនពឹងលើអត្រាប្តូរប្រាក់។ របាយការណ៍បង្ហាញសរុបពីររូបិយប័ណ្ណ។

**បើបញ្ចូលការបង់ខុស?**  
ប្រើ **លុបចោល**។ កំណត់ត្រាដើមនៅតែមាន។ បើត្រូវសងលុយអោយសិស្ស ប្រើ **សងប្រាក់** (សងពេញ)។

**បើផ្ទេរសិស្សទៅថ្នាក់ផ្សេង?**  
ប្រើផ្ទេរថ្នាក់។ ប្រវត្តិថ្នាក់ចាស់នៅតែមើលបាន។

**តើឪពុកម្តាយទទួល Telegram ដែរឬទេ?**  
ទេ។ សារទៅ Admin chat តែប៉ុណ្ណោះ។

---

## 14. ទាក់ទងជំនួយ

បើចូលមិនបាន បង្កាន់ដៃមិនចេញ ឬចង់កែឈ្មោះសាលា/និមិត្តសញ្ញា សូមទាក់ទងអ្នកគ្រប់គ្រងប្រព័ន្ធដែលបានដំឡើងឲ្យសាលា។

កុំចែកពាក្យសម្ងាត់ Admin ជាសាធារណៈ។ ផ្អាកគណនីភ្លាម បើបុគ្គលិកលែងធ្វើការ។
