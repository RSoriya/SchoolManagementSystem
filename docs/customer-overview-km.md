# School Management System · V1

**ប្រព័ន្ធគ្រប់គ្រងសាលាភាសាអង់គ្លេស និងកុំព្យូទ័រ**  
សម្រាប់សាលាមួយសាខា · ប្រើដោយអ្នកគ្រប់គ្រង (Admin) · ភាសាខ្មែរជាចម្បង

---

## ប្រព័ន្ធនេះជួយអ្វី?

Admin អាចធ្វើការងារប្រចាំថ្ងៃនៅកន្លែងតែមួយ៖

1. បញ្ចូលសិស្ស រួចដាក់ចូលថ្នាក់ (នៅទំព័រសិស្ស ឬទំព័រថ្នាក់ — មិនមានម៉ឺនុយដាច់ដោយឡែក)
2. ទទួលបង់ថ្លៃសិក្សា រួចចេញបង្កាន់ដៃភាសាខ្មែរ (ក្រដាស A4)
3. មើលនរណាមិនទាន់បង់ ឬហួស Due Date
4. មើលចំណូល USD / KHR ហើយទាញ Excel ឬបោះពុម្ព
5. ទទួលការជូនដំណឹង Telegram មុន Due Date

## ច្បាប់សំខាន់ៗ (V1)

- **បង់ពេញមួយលើក** — មិនមានបង់ផ្នែកខ្លះ
- **Due Date កំណត់ដោយដៃ** — ប្រព័ន្ធមិនបង្កើតវិក្កយបត្រខែស្វ័យប្រវត្តិទេ
- **USD និង KHR ដាច់ពីគ្នា** — មិនបម្លែងអត្រាប្តូរប្រាក់
- **ថ្លៃយឺតបញ្ចូលដោយដៃ** — មិនគិតស្វ័យប្រវត្តិ
- **សងប្រាក់បានតែពេញ** — ការបង់ដើមនៅតែរក្សាទុក
- **ប្រវត្តិមិនលុប** — ផ្ទេរថ្នាក់ លុបចោលការបង់ សងប្រាក់ រក្សាកំណត់ត្រាចាស់
